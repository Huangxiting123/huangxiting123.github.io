# 晰烁画流 · XishuoFlow

XishuoFlow 团队开发的 Windows 电商海报工作流工具。

- [访问官网与使用教程](https://xishuoflow.civilcake17.chatgpt.site)
- [登录并下载 EXE](https://xishuoflow.civilcake17.chatgpt.site/login)

## V0.8.0 工作流程

原图 `_1.jpg` → **统一角度变化** → 分路海报生成 → 人工初检 → Real-ESRGAN 画质增强 → 最终质检 → 备份并替换 `_result.jpg`。

角度变化拥有独立列表与窗口。全部线程共用一份角度提示词；海报提示词按线程单独编辑。初检不合格时复用已有角度图重新生成海报；需要时可手动“重做角度”。通常一张新任务调用两次生图 API。

## 使用教程

1. 使用发行账号登录官网、下载 `XishuoFlow.exe`，运行后用同一账号登录工作台。
2. 在“设置”中填写并点击“确认设置”保存自己的图生图接口、模型名称和 API Key。默认接口为 `https://api.artflow.vip/v1/images/edits`，实际兼容性以平台为准。
3. 点击“导入文件夹”，先选择 1—64 路并发，默认 20 路，再选总目录。程序递归读取 `_1.jpg`，平均分配给各路。
4. 在“提示词工作室”中编辑全局统一的角度提示词及每路海报提示词，点击“确认提示词”后再开始。未确认的编辑只作为草稿，不会被生成任务使用。
5. 在“待初检”打开独立窗口，对比原图与海报。合格自动增强；不合格返回原路重新生成海报。按钮操作后自动切换下一张。
6. 在“待替换”最终质检。点击“终检合格，待替换”或单张“最终合格并替换”。一键替换仅处理人工终检合格的图片。
7. 原图与其他文件保持原样，旧结果替换前备份。最终结果宽×高与原始 `_1.jpg` 完全一致；模型比例不同时等比缩放补边，禁止拉伸或裁切。

目录示例：

```text
产品总目录/
  500818/
    500818_1.jpg
    500818_result.jpg
    500818_CH.txt
    500818_EN.txt
```

## 界面

V0.8.0 采用浅灰背景、白色圆角卡片、蓝色主操作、侧栏导航和分阶段任务列表。初检、终检与登录窗口使用统一的简洁界面。

## 发行说明

Windows 64 位，内置 Python 运行时，无需另装 Python。首次运行解压环境；本地画质增强需要支持 Vulkan 的显卡和驱动。使用需联网账号校验；API 额度自行提供。任务与备份沿用 `%LOCALAPPDATA%/PosterFlow`，升级保留历史进度。

Real-ESRGAN 可以增强清晰度，无法保证修复错字或扭曲文案。请执行最终人工质检。

本目录是可直接部署在 GitHub Pages 的静态官网，含教程、FAQ 和品牌资产。登录与受保护的下载由正式官网服务端处理，GitHub Pages 无服务器运行环境。所有账号密码、API Key、管理密钥均未提交到本仓库。

## 源码与验证

源码需要 Python 3.11+、Tk、Pillow 与 CustomTkinter。Windows 打包可运行 build_windows.bat。账号验证需要联网。

核心流程测试与 Linux Tk 界面模拟检查已通过；Windows 实机、真实 Vulkan 显卡及 Artflow 付费生图调用尚未在当前环境验证。

依赖：Python、Tcl/Tk、Pillow、CustomTkinter、darkdetect、packaging、Real-ESRGAN NCNN。随程序保留第三方许可证。

## 设置确认、主题与初始化

- API 地址、模型、API Key、线程数和界面风格需点击“确认设置”才生效。
- 角度与各路提示词需点击“确认提示词”才生效。侧栏“确认全部设置”可一次确认所有修改。
- 编辑不再自动保存，也不会在开始、质检退回或退出时自动应用。已有请求保留提交时的参数快照。
- 设置页可选择日间、夜间、护眼三种界面风格，确认后同步主窗口和质检窗口。主题不修改图片颜色。
- “初始化未完成任务”保留已完成任务；“初始化全部任务”也重置已完成任务；两者均回到角度变化阶段，下次开始重新调用 API。
- “清空任务列表”归档本轮任务和调用记录后清空列表，可重新导入目录。三种操作均先归档 SQLite 数据库，保留产品目录图片、生成文件和备份；API 参数及提示词保持不变。
- 初始化前须暂停并等待在途请求、增强和替换完成，操作前会显示确认说明。
- “官网与开发者”显示官方网站及微信 Mockingbird---0，用于 API Key 购买咨询、配置协助和软件支持。
