# 续在 STILLHERE 开发工作副本（未发布）

最新开发内容与测试结果先阅读 WORKING_NOTES.md；已发布到官网的进度仍为0.6，见 RELEASE_0.6.md。原有下文为0.1历史说明，不作为当前功能清单。官网：https://huangxiting123.github.io/stillhere/ 。当天结束后再统一更新官网。

需要 Node.js 22 或更新版本。双击 start.cmd 后打开 http://127.0.0.1:4317 。

已实现：人物档案、人工录入人生记忆、关键词记忆检索、持久聊天记录、全部资料 JSON 导出。数据存于 data/persona.json，重新启动仍可读取。请备份该文件；本地存储不代表永久不会丢失。

默认演示模式只做记忆检索，不假装生成自然对话。真实对话需要在启动前配置以下环境变量（密钥仅在服务端使用）：

- PERSONA_API_URL：兼容 Chat Completions 的完整接口 URL
- PERSONA_API_KEY：服务密钥
- PERSONA_MODEL：供应商实际支持的模型标识

服务仅监听本机。此版尚不具备登录隔离、数据加密、云备份、声纹复刻、形象驱动、摄像头识别和视频通话，不适合直接对外运营。

运行检查：npm test 。项目无第三方依赖。

后续顺序：完善资料采集与记忆检索 → 接入并验证真实文本模型 → 语音对话 → 经本人授权的声音与形象复刻 → 视频通话与移动端发布。每阶段需要实际验证后才能称为完成。

原 V2 压缩包已在历史文件中定位，但本次未成功解包，因此此开发版为独立实现，并未假定已继承旧源码。
