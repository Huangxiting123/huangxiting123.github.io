# 续在 STILLHERE

当前开发版本：0.7.0-dev.10。Windows 10/11 64位预览版。

## 当前能力

- 人物档案、联系人称呼与语气配置、按联系人限制记忆访问。
- 原文归档、分段记忆抽取、人工审核、重复及冲突处理。
- 记忆正文搜索，按类型、状态、关联人物组合筛选。
- 关键词与可选向量检索、关系和近期记忆召回、回复参考记忆展示。
- 可配置文本模型、ASR转写、回复朗读与基础人设校验。
- 五个工作区、虚构示例引导、本地持久化和所有者数据导出。

## 本地运行

安装 Node.js 22或更新版本，在本目录运行 `node server.mjs`，打开控制台提示的本机地址，使用控制台中的所有者凭证登录。也可运行Windows预览EXE，在控制窗口复制凭证。数据默认保存于data/persona.json；EXE使用独立的本机用户数据目录。

运行回归测试：`npm test`。项目无第三方npm依赖。真实模型与语音服务可在设置页配置；未配置时为明确标注的检索演示。服务密钥不随源码分发。

独立stillhere-dev分支推送触发Windows测试、EXE打包、自检和GitHub预发布。通过测试后，EXE及构建哈希记录出现在仓库Releases。构建说明见desktop/README.md。
