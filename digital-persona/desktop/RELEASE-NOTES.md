# 续在 STILLHERE 0.7.0-dev.10

Windows 10/11 64位开发预览版。

- 对话、记忆、人物关系、人物档案、设置五个工作区。
- 首次使用可载入虚构示例，体验记忆对话。
- 记忆支持正文搜索、类型、确认状态和关联人物组合筛选。
- 关联人物表示记忆涉及谁；访问权限仍需另行设置。
- 回复支持展开查看已授权的本次召回参考记忆，所有者可核对原文证据。
- 本地数据独立保存，退出与升级后保留。

双击 Stillhere-Preview.exe，复制控制窗口中的访问凭证，在打开的界面中登录。已有用户请先关闭旧版控制窗口，再打开新版。

真实模型及语音服务需在设置中配置。当前尚未实现音色克隆、人脸识别、数字人视频通话。程序未签名。真实页面交互与音频设备仍待实机验收。

验证：47项源码回归通过，EXE自检覆盖运行时、HTTP、界面模块、鉴权、记忆对话、重启数据保留与进程退出。
