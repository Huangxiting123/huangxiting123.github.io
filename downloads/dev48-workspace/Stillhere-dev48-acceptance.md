# 续在 dev48 · 统一工作台与交互改版

关闭旧客户端，安装到原目录（建议 E 盘）。沿用现有模型磁盘、记忆、人物、声样、素材、API 配置与加密人生访谈，不重新下载模型。本版按照提供的深绿、米白、金色参考图落地实际界面。

## 功能重新分布

| 主入口 | 当前窗口内的功能 |
| --- | --- |
| 空间总览 | 真实资料状态、四步引导、下一步操作示例、快捷入口 |
| 和分身聊天 | 文字对话、本人声音朗读、继续编辑下一条草稿 |
| 分身资料 | 基本资料与表达、外观与环境、专属声音、模拟自拍、习惯与作息 |
| 人生与记忆 | 人生访谈、语音采集、记忆收藏、记忆时间线 |
| 人物关系网 | 人物档案、照片、关系画布、本人微信绑定 |
| 微信连接 | 扫码、回复方式、自动回复开关、语音/图片配置检查 |
| 设置 | API、本地模型安装与状态、界面动效、折叠的旧版兼容工具 |

原先独立的声音、自拍、时间线等菜单归入分栏，日常操作集中在主窗口。旧版兼容工具只保留一个折叠入口，供少量高级配置/旧素材操作使用。原接口与数据保留；尚未执行的回复延迟不会作为当前可用的控制项展示。

## 按顺序验收

1. UX01：首次进入检查七个主入口与三组导航：开始使用、培养与记忆、连接与设置。深绿侧栏、米白内容区、金色主行动按钮与参考图方向一致；1080×720下主入口可访问，内容可正常滚动，不应出现横向溢出。
2. UX02：首页显示真实的已确认记忆、表达示例、声样状态、环境栏目与人物数量，不使用示意图中的72%等虚构成长分数。“模型已配置”表示配置状态，不能替代真实推理验证；声样已保存也不等于手机语音已送达。
3. UX03：四步引导包含个人资料、声音样本、生活环境、连接微信；已有资料自动识别。下一步按实际缺项推荐，模型未配置时先到设置。点击操作示例应出现对应说明，再跳到该项操作，不能触发录音、云端生成或微信发送。
4. UX04：进入分身资料，检查五个分栏。基本介绍与说话表达保留；表达示例现在可编辑或删除，不必重新新增同样内容。所有涉及删除的数据仍须本人确认，不会为“去重复”自动删个人记录。
5. UX05：在资料页输入未保存的介绍，切到声音页再回来，文字仍在。其他页面成功保存数据刷新首页时，不应覆盖正在手改的基本介绍。点击品牌回到总览也不会重载整个应用；退出软件仍需先保存重要稿件。
6. UX06：从已有音频/视频选取待授权声样。当前支持可解码的65秒以内素材，保存开头5—15秒，逐字填写该段声音原文后另行授权。选取素材不自动授权；不足5秒、音量太低或无法解码要明确提示，不能冒充成功。切走声音录音页会停止尚未完成的录音，不继续后台收音。
7. UX07：习惯与作息在当前窗口管理爱好、思考案例、文字地点、作息与本人自述状态。可从已有生活环境栏目导入地点名称/说明，不复制或删除照片。文字地点与环境照片用途不同，导入后说明可独立编辑。已有旧版数据应原样读出。
8. UX08：添加作息时选择地点、星期、起止时间与活动；重叠时段应被拒绝，不覆盖原作息。删除仍有关联作息的地点要先处理引用。本人当前状态有有效期，清除/过期后不再作为当前信息；作息模拟仍明确标记，不代表实时定位。
9. UX09：人生与记忆的四个分栏保留原有能力：私密故事/内心分析、普通语音采集、确认记忆、时间与人物归属。私密人生访谈仍不自动进入普通记忆、微信回复或常规导出。自定义环境栏目、人物关系画布、照片授权等原流程继续可用。
10. UX10：主要操作有清楚的按下反馈、光圈、悬停与键盘焦点；正在处理的按钮和顶部状态提供反馈，避免重复提交。同一按钮处理中不重复执行；失败会有可关闭的提示，原数据不因此删除。危险操作以独立色调区分。
11. UX11：切页淡入、分栏选中、高度溢出时的横向分栏滚动、展开反馈、滚动阅读条和回顶按钮可用。切换分栏保留每页的滚动位置。保持系统原生滚轮习惯，关系画布拖动/缩放不被页面动效接管。
12. UX12：用方向键/Home/End切换已聚焦的分栏，选中状态与侧栏所属分组同步；有明确焦点边框。页面切换后焦点回到当前标题，不能落到隐藏的输入控件。
13. UX13：在设置选择“减少动画”，点击与切页不再产生移动动画；系统开启减少动态效果时也应遵守。关闭/减少动画不影响按钮、画布、保存或回顶。动效偏好重启后保留，保存到本机的仅是界面偏好，不是输入的隐私草稿。
14. UX14：模型回答等待期间，可继续输入下一条草稿。原回答返回后不清空新写的草稿；未发送的草稿不能进入聊天记录。弹窗、滚动、草稿与按钮状态应在错误/取消后恢复，不长期停留在“处理中”。
15. UX15：设置的图片/文字固定内容测试折叠到可选接口诊断中，实际自拍验证在模拟自拍分栏；仅查看/切页不会产生付费请求或微信发送。旧版窗口只在明确点击兼容入口时打开。
16. UX16：关闭再开，核对原记忆、人物、素材、作息和加密人生访谈仍在；本机凭证不变，关闭时服务连接描述应正常清理。微信语音/图片实际送达仍需手机验收，本次 UI 测试不代表真实微信已送达。
