# dev.28 功能验收目录

交付日期：2026-11-06。目标：把采集资料真正保存到本机素材库，重启后可查看。
请按编号依次验收；每项记录“通过 / 未通过 / 未测试”。未通过时记录步骤、提示文字与截图，遮住凭证。先使用普通测试素材。

## 准备

- 停止旧版（原启动窗口 Ctrl+C），完整解压dev.28运行包，双击“启动本机版.cmd”。不要只替换单个文件。
- 使用新打开的地址登录；所有者凭证继续保存在 %LOCALAPPDATA%\Stillhere-Local\owner.token。
- 保持iPhone Camo Camera及电脑Camo Studio运行。摄像头选择Camo，麦克风选择实际收音设备。
- 本轮使用档案所有者账号，不需要确认交流身份，也不需要配置模型、转写或朗读服务。
- 每轮录制最多60秒/100MB；素材库本版上限200条或2GB，达到任一上限会拒绝新保存。页面显示用量，不代表磁盘剩余空间。

## 必验项目

| 编号 | 功能 | 操作步骤 | 通过标准 |
|---|---|---|---|
| A01 | 新入口 | 登录后查看页面 | 默认显示采集和本机素材库；进阶通话测试折叠 |
| A02 | 录像采集 | 输入标题“视频测试01”，选择形象与说话视频，勾选录制保存同意，打开设备，开始采集，说话5—10秒后停止 | 有预览；停止后设备关闭，先显示正在保存，随后显示“已保存到本机素材库” |
| A03 | 视频回放与收音 | 回放本轮视频，再在素材库选择该条“回放 / 下载” | 画面和自己的声音可回看；库里只有一条视频测试01。Camo画面正常但无声音时检查浏览器麦克风选择 |
| A04 | 仅声音 | 删除本轮临时素材以开始下一轮；标题“声音测试01”，选择仅声音，重新打开设备，录5—10秒后停止并回放 | 只申请麦克风，本轮不新开摄像头；声音可听见，素材库新增声音记录 |
| A05 | 故事原文 | 在本机素材库填写故事标题“故事测试01”，输入一段故事，点击“保存故事原文” | 列表出现故事；点“查看 / 下载”可看原文；显示“已保存，待整理”，不冒充已确认记忆 |
| A06 | 刷新保留 | 确认各条都已保存，再刷新网页、重新登录 | 原来的视频、声音和故事仍在素材库，仍可查看或回放 |
| A07 | 重启保留 | 确认没有正在保存的任务，Ctrl+C停止服务，重新启动并登录 | 地址可能换端口；使用新地址后资料仍在，回放可用 |
| A08 | 下载副本 | 在素材库选择一条素材，点击“下载选中素材”，在下载目录打开 | 文件能打开，内容与选择的一致。音视频可为webm，故事为txt；播放器不支持webm时可用支持该格式的浏览器检查 |
| A09 | 临时素材与原件 | 新录一条并确认已保存，再点“删除本轮临时素材”，刷新素材库 | 页面临时播放器清空，但素材库原件仍在 |
| A10 | 取消录制 | 打开设备，开始录制后点击“关闭设备 / 取消录制” | 设备关闭；未完成的这轮不产生新的素材库记录 |
| A11 | 删除原件 | 对一条测试素材点素材库内“删除”，确认；刷新或重启再查看 | 该条不再出现、选中回放关闭；不影响其他素材。已下载的副本不会自动删除 |

注意：在录制中切换后台或功能区会取消当前录制。已保存内容保留。未保存成功前不要刷新或退出。

## 补充验收（有条件再做）

- A12 保存失败与重试：用浏览器开发者工具模拟网络断开后完成录制，应该显示保存失败、保留本轮临时素材并允许下载。恢复网络后点“重试保存到素材库”，应只出现一条记录。无需为了此项更换系统网络设置；不熟悉可标记未测试。
- A13 联系人隔离：用联系人账号登录，不应显示所有者素材库的名称、内容和回放；不能管理原始素材。当前不支持把素材库原件分享给联系人。

## 本轮不验收

自动语音转写、模型拆分故事、审核入记忆、语气训练、声音复刻、真人形象制作、数字人视频通话尚未在本轮接通。保存原始素材并不等于已经训练。iPhone和Windows实际采集需要本轮实机验收，开发环境的浏览器模拟设备测试不能替代。

## 数据与备份

本机启动器将素材保存在 %LOCALAPPDATA%\Stillhere-Local\data\assets，未发送外部模型服务。网页素材库的删除会删除本机索引和文件；已下载副本需自行处理。原有“资料导出”不包含这些二进制素材。需要完整备份时停止服务，备份整个Stillhere-Local目录（含登录凭证，请自行保管）。旧dev.27只下载到电脑的文件不会自动导入本素材库，本轮没有历史文件导入功能。
