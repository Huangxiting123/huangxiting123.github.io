# 续在 dev40 · ArtFlow 本机配置与诊断

这是 API 配置与兼容协议测试版，尚不是自动自拍功能。平台公开文档目前未能读取，`/v1/models`、`/v1/images/generations`、`/v1/chat/completions` 按 OpenAI 兼容方式尝试，不承诺该平台全部模型支持这些参数。API 实际权限和结果由你的电脑访问平台验证。

## 安装

关闭旧续在客户端和旧 CMD 启动窗口，安装 dev40 到原客户端目录（建议 E 盘）。保留 E:\Stillhere-Models 与 %LOCALAPPDATA%\Stillhere-Local。无需重新下载现有大模型。打开「续在 → 设置与工具」。

## 顺序验收

1. AF01：找到「连接你的 ArtFlow 服务」。固定服务域名为 https://api.artflow.vip，连接测试不会上传照片、记忆或聊天。
2. AF02：在本机填写 API Key。图片模型完整名称从 ArtFlow 模型卡片复制；文字模型可选。点击「保存到本机安全存储」。密钥输入框清空，页面不回显密钥。
3. AF03：点击「测试鉴权与获取模型列表」。该操作只请求模型列表，不主动生成图片或聊天。成功后模型输入框可使用返回的候选列表；这不代表模型支持参考人像。
4. AF04：若鉴权失败，页面应区分 HTTP 401、403、404、429、5xx 或网络连接失败，不显示平台原始错误正文或密钥。截图只保留诊断结果，不要截图填写中的 Key。
5. AF05：只有勾选「可能消耗平台额度」后才可点击生成测试图片。只生成一张杯子图片，不发送私人资料；成功若返回 Base64 PNG/JPEG 可预览。如果仅返回 URL，页面会说明图片内容尚未下载验证。
6. AF06：选填文字模型后可测试一个固定的“Reply with OK only.”请求；可能计费。成功不会替换原有本地对话模型。
7. AF07：遇到超时，不会自动重试。图片请求可能已在上游执行并计费，先在平台查看调用记录，避免重复点击。
8. AF08：重启客户端，配置仍在，Key 不回显。留空 Key 再保存会沿用此前密钥；Windows 安全存储不可用则拒绝保存，不降级为明文。
9. AF09：删除本机密钥后，配置与预览清空，再测试会提示先保存配置。删除本机配置不会撤销平台令牌，撤销需到 ArtFlow 控制台操作。
10. AF10：测试原有记忆、声音与微信文字功能仍可使用。当前新增功能不生成本人自拍、不上传参考人像、不向微信发送图片，也不自动切换原本的本地模型。

## 安全与测试范围

API Key 使用 Windows DPAPI（Electron safeStorage）加密，独立保存在 Stillhere-Local/artflow-api.json，不写入人物档案、导出记忆或界面状态。密文绑定当前 Windows 账户；换电脑/账户需重新填写。测试结果仅给出受限诊断，不回显平台原始响应正文；不自动跟随重定向，不自动重复计费请求。

验证包含模拟 API 的密钥保存/恢复/删除、HTTP 错误分类、重复生成拦截、固定公开测试提示词、浏览器配置交互，以及 Windows 安装后 DPAPI 实际加密解密和客户端回归。不包含使用你的 ArtFlow Key 的真实在线调用、参考人像效果或微信图片送达。
