# 续在 dev45 · 分身资料档案

关闭旧客户端，安装到原目录（建议 E 盘）。保留旧模型、记忆、人物、照片、声样与 ArtFlow 配置；无需重新下载模型。

## 按顺序验收

1. DA01：进入新增的「分身资料档案」。顶部显示自拍主参考和声音样本状态，可进入「我的自拍」「我的声音」继续录入；故事语音采集仍是独立用途。
2. DA02：选择“个人照片”，填写名称，上传一张清晰照片（128—8192像素，原文件15MB以内）。选择本机收藏授权后保存。图片会缩放到最长边768像素，最多30条素材；不会提取人脸特征或自动发送到模型。
3. DA03：可分别收藏正脸、侧脸、全身照片。点某张“设为自拍主参考”只把它带到自拍设置，需再勾选独立云端授权并保存后才实际更换；原自拍主参考在此之前不变。当前生成的主身份参考仍是一张，不会把所有人像自动一起上传。
4. DA04：从声音录入入口录制5—15秒本人声样，填写逐字原文、保存授权。已有声样继续沿用，不因添加服饰或照片而替换。普通话/川渝故事录入在“语音采集”，不会自动当作克隆声样。
5. DA05：选择“服饰衣服”，上传衣服或穿搭照片，名称例如“常穿深蓝外套”，细节例如“棉质、袖口浅色线、散步穿”。仅勾本机收藏时保存，卡片应显示“仅本机收藏”，“下一次自拍的补充参考”不应出现这张图。
6. DA06：同样可添加“配饰随身物”“常见环境”“其他外观素材”。环境建议注明地点与布局，配饰注明颜色、材质、佩戴位置；没有依据的信息留空。关系网中的亲友照片不会自动进入本人分身档案。
7. DA07：编辑服饰等素材，明确勾选“允许图片和说明随自拍发送到 ArtFlow”后保存。下方显示实际将使用的补充参考。每次最多两条：按服饰、配饰、环境、其他的顺序，各类取最后保存的一条；多个已授权服饰会选最后保存的一份，要改默认搭配可以编辑后保存或撤销旧条授权。
8. DA08：实际自拍请求带主身份参考，加上被选中的补充图片和文字说明，不会只存图却完全不调用。当前聊天明确的穿搭要求优先于默认素材。多图使用 OpenAI 兼容 image[] 方式，平台/模型不支持时明确报错，不会自动改成无参考生成，也不会重试计费。
9. DA09：在“我的自拍”测试或微信请求“发一张穿着常穿外套的自拍”。检查脸、衣服与场景是否符合预期。多图是否可用、衣服细节是否一致、人物相似度，需你使用真实 ArtFlow 配置实测；本版不保证逐像素复刻。
10. DA10：撤销单条素材的生成授权或删除素材，后续选择列表应移除；进行中的旧请求会在返回/发送前因素材版本变化被阻止。上游已接收的请求可能计费，已发送微信图片不会自动撤回。
11. DA11：重启客户端检查分类、图片、说明与授权保留；筛选类别能只看对应素材。多窗口旧版本修改应返回冲突，需重新加载；删除分身素材不删除独立声样、自拍主参考、经历记忆或关系网人物照片。
12. DA12：素材管理接口仅所有者可读写，联系人不能读取图片或说明。资料保存在 Stillhere-Local 的 data/persona-materials.json，不在普通聊天上下文和常规 JSON 导出中；备份这些图片请备份整个本机资料目录。授权生成时仅选中的补充素材随自拍请求发到 ArtFlow。

## 验证范围

已用真实浏览器验证分类上传、照片预览、保存/修改/删除、独立授权、生成选材、选择主参考与声音入口，以及重载保留。自动化验证本机存储与版本冲突、联系人隔离、多图上传身份图排首、补充图片和文字进入生成请求、撤权后拒绝旧结果、上游失败不重试。Windows 安装后检查档案控件和素材持久化。API、微信、声样生成使用测试夹具；未使用你的真实照片、声音或 API Key 验收视觉/声音效果。
