# dev.30 功能验收目录：视频与录音本地自动转写

交付日期：2026-11-06。本轮目标：已保存视频/录音 → 自动提取声音 → 本机识别中文 → 自动保存待校对稿 → 本人校对后确认入记忆。

## 准备

1. 先停止旧版，完整解压dev.30运行包。包内含本地引擎和模型，约100MB，不要只复制网页文件或删除runtime/asr。
2. 双击启动本机版.cmd，用新打开的地址和原所有者凭证登录，旧素材继续保留。不要运行旧目录的程序。
3. 不需要购买语音服务、不需要密钥、不需要配置朗读，也不需要确认通话身份。处理在运行软件的电脑上完成。
4. 转写已保存素材不需要再开摄像头或麦克风。新采集仍需设备授权。
5. 使用新版Chrome或Edge。建议先试5—15秒清晰普通话，之后再试四川口音。语音识别会有错字，人名、数字和时间要本人核对。本轮不保证方言准确率。

## 顺序验收

| 编号 | 功能 | 操作 | 预期结果 |
|---|---|---|---|
| C01 | 升级保留 | 登录，打开原“小学记忆”视频并回放 | 原视频与声音正常，没有因升级丢失 |
| C02 | 组件就绪 | 点视频的“整理 / 校对入库” | 自动滚动到整理区，显示“本地转写组件已就绪”及“自动转写声音”按钮；不要求ASR/TTS密钥 |
| C03 | 视频自动转写 | 勾选本机转写同意，点“自动转写声音”；若有旧校对文字，先决定是否同意替换 | 先显示提取声音，再显示本机识别；完成后文字自动填入并显示“自动转写已保存为待校对稿”，原视频不变。不要把与实际语音明显无关的文字判为通过 |
| C04 | 不提前入记忆 | 自动转写后，尚不勾选入库确认，检查记忆页 | 不出现本轮新增的已确认记忆；转写只是待校对稿 |
| C05 | 校对与确认 | 修改听错的人名/时间，保存校对稿，检查片段和访问范围，再明确确认 | 按所选范围入记忆，原文证据为校对后的文字；不修改原视频 |
| C06 | 刷新与重启保留 | 对另一条测试素材完成转写但不发布，刷新重新登录，再停止并重启程序打开整理 | 转写稿仍在，仍待校对，不需要重新识别 |
| C07 | 录音自动转写 | 新录一条5—15秒声音素材，停止保存后进入整理，自动转写 | 没有摄像头也可完成；文字对应实际说话内容 |
| C08 | 覆盖保护 | 已有校对文字时再点自动转写，在确认框选择取消 | 现有文字保持；确认继续才会替换。已入记忆的素材不能再自动覆盖原校对稿，后续修改去记忆页 |
| C09 | 取消识别 | 对一条未入库的测试音视频点自动转写，识别期间点“关闭整理” | 整理区关闭；当前任务被取消。重新打开时，已存在的校对稿保留，不应在取消后突然覆盖。很短素材可能在点击前已完成，可标记未测试 |
| C10 | 手工故事回归 | 保存一段文字故事，进入整理并校对 | 仍可正常校对和入库，文字故事不显示语音转写按钮 |

## 有条件再验

- C11：较长素材。录40—60秒，前后各讲不同内容，转写后检查后半段也存在。每条最多65秒，超过会拒绝。系统按20秒声音片段识别，边界附近可能有错字或断句，需人工校对。
- C12：无声素材。对真正无声的测试素材转写，应提示没有有效语音；实际环境噪音仍可能被误识别，不保证自动区分所有噪声。
- C13：离线。先保存测试素材，再断开互联网，在仍运行的本机地址中对该素材转写，应不要求联网服务。无需重新录制或改变Camo连接。
- C14：两窗口修改冲突。窗口A转写时，窗口B保存新的校对稿。A的迟到结果应报整理稿已变化，不覆盖B。很短素材可能难以复现，可标记未测试。

## 问题处理

- “组件未就绪”：确认运行完整dev.30目录，里面有runtime/asr的exe、两个onnx模型及tokens文本；停止旧版后重新启动新版。无需填写云端转写密钥。
- “无法解码声音”：先确认素材回放有声音；旧损坏文件、浏览器不支持的编码可能无法处理，可以重新采集。已验证WebM/Opus、MP4/AAC视频及WAV样本的完整链路。
- “运行失败”：记录提示并发截图，检查组件是否完整以及系统是否拦截引擎；不要为了运行而关闭安全防护。Windows实机尚待本轮验收。
- “已有转写任务”：本版同一电脑同时只处理一项；稍后重试。
- “整理稿已变化”：重新打开整理查看最新稿，不要覆盖另一窗口已确认的修改。
- 识别时关闭整理可取消。正常完成/取消会清理临时声音文件；断电或强制结束进程不保证清理完成。原始素材库文件不受影响。

## 本轮边界与验证记录

这是预训练识别模型的本地推理，不是训练用户声音。自动识别不等于事实确认，仍需本人审核。仅提取声音，不理解视频中的无声动作、五官或微表情。尚未制作专属声音、真人数字人形象或完整视频通话。

开发验证：145项Node测试通过，使用Node22运行；真实中文样本通过WAV录音、WebM/Opus视频、MP4/AAC视频、40秒后有语音的长音频链路验证。验证了原件未改变、待校对稿保存、明确确认入库、取消、并发修改保护。Linux真实模型运行与浏览器验证不能替代Windows/iPhone实机；本包Windows引擎仅做官方来源、SHA256、PE x64及依赖检查。
